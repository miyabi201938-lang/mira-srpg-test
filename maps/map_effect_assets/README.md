# マップ演出素材保管フォルダ

マスターマップ上に重ねて使用する演出素材を保管するフォルダ。

## 素材カテゴリ
- cities/：都市・拠点アイコン（王都、要塞都市、町村、港、塔、遺跡など）
- terrain_blocks/：凸状の舞台・地形ブロック（平原、森林、山岳、雪原、砂漠、湿地、火山、古代遺跡など）
- routes/：進軍・進行・作戦・移動ルートの矢印や線
- markers/：目的地、イベント、探索、戦闘、重要地点などのマーカー
- faction_markers/：自軍・敵軍・中立拠点などの表示素材
- special_effects/：特殊地点、魔法、演出用エフェクト

素材は原則として透過PNGで保存し、マスターマップの上に重ねられるよう個別素材として管理する。マスターマップ自体は変更しない。
