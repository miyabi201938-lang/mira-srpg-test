# ヘックス・マスター（基準仕様）

**状態：寸法・形状仕様の記録。画像マスターは未作成／未確定。**

## ゲームCSS準拠の基準
- 1ヘックスのサイズ：56×44 px
- 横方向の中心間隔：42 px
- 縦方向の中心間隔：44 px
- 奇数列：偶数列に対して22 px下へずらす
- 形状：フラットトップ（左右に尖り、上下は平ら）

## 六角形の頂点（セル左上を原点）
- (14, 0)
- (42, 0)
- (56, 22)
- (42, 44)
- (14, 44)
- (0, 22)

CSS相当の形状：
`polygon(25% 0, 75% 0, 100% 50%, 75% 100%, 25% 100%, 0 50%)`

## 配置計算
- x = 基準x + 列番号 × 42
- y = 基準y + 行番号 × 44 + (列番号が奇数なら22)

## 制作時の固定ルール
- ヘックス形状・サイズ・間隔・列ずらしを独自に変更しない。
- 以後の平地／森マスターはこのヘックス規格を基準に制作する。
- **1ヘックスにつきユニットは最大1体。重複配置禁止。**
- この仕様書はゲームCSSを参照した数値仕様。確認用の画像マスターは別途作成し、ユーザー確認後に確定する。

## 確認元
テスト版リポジトリの `style.css`（`.unit-token`）と `game.js` のヘックス配置計算。
