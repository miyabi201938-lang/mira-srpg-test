# フィールドマップ・マスター

このフォルダは「興亡のヴァルディア」のフィールドマップ制作で使う基準素材（マスター）を保管する場所。

## 制作ルール
- マスター素材は個別に作成・確認・確定する。
- 確定したマスターは原則として直接変更せず、マップ制作では複製・組み合わせて使う。
- マスター同士を合成してフィールドマップを作る。
- 形状・寸法・配置基準を途中で変えない。変更が必要ならマスター自体を確認してから更新する。

## マスター作成順
1. ヘックス（形状・寸法・配置基準）
2. 平地
3. 森
4. 必要に応じて追加地形・装飾マスター

各マスターは個別ファイルと素材を用意し、確認後に確定する。
