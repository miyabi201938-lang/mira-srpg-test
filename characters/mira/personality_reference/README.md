# ミラ人物参考資料

このフォルダは、**戦闘用デザイン・フィールド用ミニキャラのどちらにも限定しない、ミラ本人の人物表現を固めるための参考画像**を集める場所。

## 収録予定
- 日常の場面（食事、休息、睡眠、会議、執務など）
- 表情（怒り、悲しみ、笑顔、驚き、疲労など）
- 顔の角度・髪型（髪をほどいた姿など）
- 私服・軍務服・季節服など、衣装のバリエーション
- 人柄、雰囲気、所作の参考になる場面

## 登録ルール
- 採用された画像をユーザーがアップロードする。
- 国旗・徽章・所属を描く場合はGitHub内の正式資料を確認し、未確認のものを創作しない。
- 画像は人物表現の参考資料として扱い、戦闘素材・フィールド素材そのものとは区別する。
- 既存の公式デザインや設定を勝手に変更する根拠にはしない。
