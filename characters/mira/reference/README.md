# ミラ公式デザイン参考資料

このフォルダは、ゲーム実装素材そのものではなく、ミラのデザインと動作を統一するための正式な参考資料を保管する場所。

## 原本資料

- **戦闘時・高頭身デザイン参考資料**: `mira_battle_design_reference.PNG`
  - 髪型、衣装、鎧、配色、マント、装備などのデザイン基準。
  - フィールド用ミニキャラをデフォルメする際の原型。
- **フィールド用ミニキャラ動作指針（改訂5）**: `mira_field_animation_reference_rev5.PNG`
  - フィールド動作、方向、アニメーション構成の正式基準。

## 制作ルール

- 戦闘時の高頭身ミラをデザインの原型とする。
- フィールドでは抜刀・攻撃しない。選択時は移動構え／警戒姿勢。
- 動作指針の一覧を省略・改変しない。
- ドット感、透明背景、コマ分離、フレーム寸法、足元基準を揃える。
- 作業・保存・更新はテスト版 `mira-srpg-test` のみ。本番版は明示許可なしに変更しない。
