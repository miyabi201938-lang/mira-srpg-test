# キャラクター素材

キャラクター設定の正式な名前・人物関係は `../character-settings.txt` を参照。キャラクターごとにフォルダを分け、戦闘専用グラフィックとフィールド用ミニキャラを別管理する。

## 初期メインキャスト
- Mira Rosen（ミラ・ローゼン）
- Gareth Glanz（ガレス・グランツ）
- Lucas Ritter（ルーカス・リッター）
- Gina Wolf（ジーナ・ヴォルフ）
- Felix Ahren（フェリックス・アーレン）

各キャラクターの素材フォルダ構成は `battle/` と `field/`。マスター画像は別途明示して固定し、派生素材はマスターを上書きしない。
