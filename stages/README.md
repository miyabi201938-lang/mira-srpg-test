# ステージ管理

「興亡のヴァルディア」のシミュレーションステージを、設定・マップ設計・実装データ・制作進捗に分けて管理する。

## 管理方針
- 各ステージは独立フォルダで管理する。
- タイトル、舞台、時間帯、作戦概要、勝敗条件、地形、移動ルール、敵AI、イベントなどの設定を記録。
- 設定ファイルと実際のマップ設計図・実装データは分ける。
- 未確定案は「案」と明記し、ユーザーの承認なしに確定設定へ変更しない。
- ステージ制作や設定変更後は、このフォルダ内の記録と開発進捗ファイルを更新する。

## ステージ一覧
- [第1面：夜森の奇襲](stage-01-night-forest-ambush/settings.md) — 防衛線を迂回する森林地帯で敵野営地を奇襲するステージ（設定策定中）

## 標準構成（各ステージ）
- `settings.md`：物語・作戦・ルール・勝敗条件
- `map.md`：実際のマップ地形とヘックス配置
- `units.md`：敵味方の初期配置と編成
- 必要に応じてイベント・演出・実装メモを追加


## 共通地形マスターとの連携（2026-11-27・案）
- 第1章マップは共通地形マスターの森林素材を使用する最初の適用先とする。
- 森の密度、獣道、草地、岩、野営地オブジェクトは共通素材を組み合わせ、章専用素材は必要な場合のみ追加。
- 今回生成した概念シートは配置イメージ確認用。個別タイル原本の完成・登録とは扱わない。
- 個別素材の確定前に、全ヘックス配置・騎兵迂回路・通行コストは正式確定しない。
